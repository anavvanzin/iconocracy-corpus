# Destination matrix

| Material | Primary destination | Why | Avoid |
|---|---|---|---|
| Active chapter, notes, fichamento | Google Drive | collaboration, comments, live editing | storing the only archival master |
| Original scan, high-resolution image, video, binary export | Dropbox | large-file preservation and version storage | treating a web derivative as the master |
| Code, structured content, taxonomy, manifest, site asset | GitHub | diffs, branches, review, deployment | committing private or licensed material publicly |
| Finished public essay, object page, atlas entry | Site through GitHub/editorial workflow | publication and discoverability | uploading raw notes directly to production |
| Unresolved fragment | Google Drive intake queue | visible research backlog | false certainty or premature publication |

## Decision questions

1. Is this the archival master, a working copy, or a public derivative?
2. Does it require collaborative prose editing, binary preservation, or versioned text/code review?
3. Is it private, restricted, licensed, or publishable?
4. Does an authoritative copy already exist elsewhere?
5. Which project, chapter, panel, or page will use it?
