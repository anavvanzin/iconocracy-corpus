# Intake metadata schema

Use fields selectively; never fill unknown values with guesses.

## Identity
- intake_id
- material_type
- title_original
- title_translated
- creator
- date_display
- date_start
- date_end
- language

## Provenance
- source_url_or_location
- source_institution
- collection_or_fonds
- identifier_or_shelfmark
- acquired_or_downloaded_at
- chain_of_reference
- access_restrictions
- rights_status

## File state
- current_filename
- proposed_filename
- file_format
- dimensions_or_pages
- checksum_if_available
- duplicate_family
- version_status

## Research use
- project
- chapter_or_panel
- research_question
- controlled_tags
- confidence
- unresolved_fields
- next_action
