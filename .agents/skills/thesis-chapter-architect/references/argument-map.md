# Argument map

## Core fields

- Research question
- Chapter claim
- Premise 1
- Evidence for premise 1
- Warrant connecting evidence to claim
- Premise 2
- Evidence for premise 2
- Rival explanation
- Counterargument
- Response
- Limits
- Chapter conclusion
- Link to thesis-level claim

## Diagnostic tests

1. Could the conclusion follow if one example were removed?
2. Is a theoretical concept doing analytic work or only naming the material?
3. Does each image or case change the argument?
4. Are chronology and causality being confused?
5. Is a typological recurrence being treated as documented transmission?
6. Does the chapter claim more geographic or historical reach than the evidence allows?
