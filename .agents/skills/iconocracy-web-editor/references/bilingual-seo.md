# Bilingual metadata and accessibility

- Give each language an authored title and description.
- Maintain explicit language links or identifiers when the platform supports them.
- Keep slugs stable and readable; do not translate identifiers that must remain shared.
- Write alt text for the page's purpose, not a keyword list.
- Separate visual description from interpretive captions.
- Include creator, date, institution, identifier, and rights in image credits when available.
- Use search phrases only when they match the page's actual subject.
- Avoid duplicate translated pages with missing canonical or language relations.
