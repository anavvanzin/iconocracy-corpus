# Content type guide

## Object page
Required concepts: stable id, title, date, creator, source, rights, visual description, interpretation, related objects, bibliography, language relation.

## Atlas panel page
Required concepts: panel proposition, ordered objects, layout or panel image, object credits, reading paths, methodological limits, related research.

## Essay
Required concepts: argument, sections, cited sources, image sequence, author and date, translation relation, further reading.

## Project page
Required concepts: purpose, methods, status, outputs, collaborators, access conditions, related repositories or collections.

## Person/profile page
Required concepts: concise biography, research areas, selected work, contact boundaries, current projects, verified links.

Adapt field names to the repository. Never impose this guide over an existing validated schema.
