# Mnemosyne Viva — pacote de assets Figma-ready

Criado para o staging editorial do novo `iconocracia.com`: **Mnemosyne Viva**, casa pública do acervo, do atlas e da pesquisa ICONOCRACIA.

## Como usar no Figma

1. Baixe o ZIP e extraia a pasta.
2. Abra o Figma e arraste `mnemosyne-viva-figma-board-16x9.svg` para o canvas.
3. Desagrupe (`Cmd/Ctrl + Shift + G`) até chegar nos grupos editáveis.
4. Transforme os grupos principais em componentes:
   - `Logo / Primary`
   - `Navigation / Light`
   - `Navigation / Dark`
   - `Card / Acervo`
   - `Card / Conceito`
   - `Stats / Strip`
   - `Icon / Acervo`, `Icon / Atlas`, `Icon / Método`, etc.
5. Importe `figma/mnemosyne-viva-design-tokens.json` manualmente como referência de variables/styles.

## Direção de arte

- Editorial, histórico, iconográfico.
- Playfair Display + DM Sans.
- Paleta ocre/sienna sobre papel creme, com modo noturno sóbrio.
- Xilogravura contemporânea, ornamentos de arquivo, cartas iconográficas e selos.
- Sem gradientes corporativos, sem cards SaaS genéricos, sem dashboard técnico como identidade principal.

## Arquivos principais

- `mnemosyne-viva-figma-board-16x9.svg` — prancha importável/editável 1920×1080.
- `mnemosyne-viva-figma-board-preview.png` — preview em PNG.
- `moodboards/mnemosyne-viva-ai-moodboard-16x9.png` — imagem gerada como moodboard visual.
- `logos/` — logotipo, monograma e selo.

- `components/` — hero, nav, cards, stats, footer.
