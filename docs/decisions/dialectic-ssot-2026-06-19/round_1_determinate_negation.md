# Round 1 — Determinate Negation (orchestrator analysis)
_belief-free seat; written before the synthesis to avoid pattern-matching_

## 1. Internal tensions (where each monk's own logic undercuts itself)
- **Monk A** concedes "o coração do coding é interpretativo" — but then demands *measurement-provenance* (event-sourcing as if there were a true value to track). If the coding is a judgment, what needs tracking is the **justification**, not a state transition. A's own concession undercuts "event-sourced DB" as the necessary form.
- **Monk B** prescribes "congelar snapshot datado + dataset card documentando quarentena e critérios + nada escreve nele." That **IS a single source of truth** with documented provenance — B reinvented A's goal (fixity + auditability) while refusing the name and the automation. B's own remedy smuggles in A's requirement.

## 2. Surface contradiction
A: quantification ⇒ empirical instrument ⇒ infalsifiable without reproducible provenance ⇒ event-sourced DB.
B: codings are arguments ⇒ no true value to proven ⇒ DB reifies false ontology + starves the thesis ⇒ freeze + prose.

## 3. The shared assumption (the prison of both)
Both slide in ONE move from the **nature of the coding ACT** to the **nature of the STORAGE ARCHITECTURE**. They conflate four distinct things:
1. the coding *act* (interpretive judgment),
2. the coding *record* (a datum),
3. the aggregate *claim* (statistical),
4. the *storage/provenance architecture*.
A reasons (3 is empirical) → (4 must be event-sourced DB). B reasons (1 is interpretive) → (4 must be none, just prose). **Neither separates (4) from the ontology of (1).** The architecture does not have to inherit the ontology of the act.

## 4. Position protection (Ricoeur — whose interest does each defend?)
- A protects the **statistical chapters** (the thesis's empirical ambition) — and the engineering constituency that finds infra morally satisfying.
- B protects **Ana's finite attention before 2027** and the discipline's actual readers (banca, historians). Both interests are real and both survive any synthesis.

## 5. Determinate negation (the SPECIFIC failure of each = signpost)
- **A fails specifically** by equating "auditable/falsifiable" with "event-sourced as measurement." The signpost: what a quantifying-humanities thesis owes is **justification-traceability of each version**, not state-transition logging of a phantom true-value.
- **B fails specifically** by inferring from "the act is interpretive" that the **aggregate claim needs no fixed, reproducible substrate.** The signpost: B's own freeze+card *is* that substrate — so the real need is **fixity + documented rationale**, which B grants while denying.

## 6. Hidden question (not "dataset or hermeneutic?", not "DB or prose?")
**"What is the minimal architecture that makes coding JUDGMENTS reproducible-as-justifications (not as measurements), at the lowest cost to Ana's attention before 2027 — and does defensibility require a *live system* at all, or just a *frozen, legible, provenance-documented artifact*?"**

## 7. Boydian decomposition → cross-domain connection
Shatter the claims to atoms: {fixity, datability, citability, justification-trace, falsifiability, low-attention-cost, no-false-precision, interpretive-ontology, single-writer-discipline, deterministic-exports}.

Both monks actually CONVERGE on: a **frozen, datable, single, documented snapshot**. They diverge only on (a) live event log vs frozen, (b) DB/automation vs prose.

**Cross-domain injection (outside both monks' domains):** the **apparatus criticus** of critical-edition philology. For 500 years the humanities have made *interpretive* editorial judgments **traceable and falsifiable without reducing them to measurements**: a critical edition freezes a text (a version), and the editor's contested readings are documented in a structured *apparatus* (variant readings + rationale), per edition, not in a live database. The apparatus criticus IS "event-sourcing for hermeneutic objects" — but it is prose+structure, frozen per release, and it is a *native humanist technology*, not an imported positivism.

This atom-set + cross-domain connection has **emergent structure neither monk holds**: provenance-of-judgment that is simultaneously falsifiable (A's demand) and non-positivist (B's demand), at near-zero new-infra cost (git already provides the version log for free).

## 8. Sublation criteria (what a real Aufhebung must satisfy here)
1. **Cancels** the false binary (dataset XOR hermeneutic; DB XOR prose).
2. **Preserves** A's falsifiability/auditability AND B's interpretive ontology + attention-scarcity.
3. **Elevates** to: the corpus is a **versioned hermeneutic artifact with a critical apparatus**; its SSOT is a *sequence of frozen, git-versioned, legible releases each carrying a documented coding-rationale* — not a live event-sourced DB, not pure prose.
4. **Sequencing** (strategy domain demands "what first"): must say what to build before writing resumes, on an attention budget.
5. **Closure:** a monk must be able to argue from it (it must be concrete enough to believe).

## 9. Misfit register (friction the synthesis will NOT resolve)
- **[Foucault / framing fossil]** "single source of truth" is an engineering term; applied to a hermeneutic object it may *be* the original category error. It serves the tooling constituency. The synthesis should rename the target (e.g., "canonical version of record").
- **[Derrida / undecidable]** "reproducibility" is loaded oppositely: A = statistical re-runnability; B = a competent reader reaching comparable readings. Same word, opposite content. No synthesis dissolves this; it must be *declared* in the dataset card.
- **[Adorno / residue]** B's attention-scarcity / "delete tools, freeze, write" is NOT fully resolved: even a frozen apparatus costs attention to build once. The synthesis must own an explicit **cost budget** and justify the one-time spend against 2027.
